## Finding Specifications

All specification files are in the `claude/` directory at the project root:
- Location: `/claude/PROMPT_[ID]_[Title].md`

Use these README files to navigate by category, or find the full list in `/claude/00_COMPLETE_DOCUMENTATION_INDEX.md`

## Contributing

When adding new specifications:
1. Create the PROMPT file in `/claude/` with the full naming convention
2. Add a reference to the appropriate category README in this directory
3. Update the master `/claude/00_COMPLETE_DOCUMENTATION_INDEX.md` file
